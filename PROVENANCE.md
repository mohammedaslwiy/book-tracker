# Learning and authorship

The original one-book example was drafted by a coding assistant. The student
changed the title and author, ran the program, committed those changes, and then
added keyboard input during a guided session. That exercise is preserved as
`examples/FirstBookDemo.java` (class name changed only).

At the student's request, the coding assistant implemented the expanded library
application, its class structure, persistence, tests, scripts and documentation.
This version should be described as an assistant-supported learning project,
not as an independently written student implementation.

No professor's solution files are included. Future personal changes can be
documented through commits and explained in the README as they are completed.
